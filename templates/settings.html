Rotation

The strip cycles CPU → RAM → GPU, showing each metric's colour for the chosen duration. At or above the warning threshold it turns solid red.

Output brightness

Off: each metric shows exactly the colour picked in its ramp. On: the colour is also scaled between the minimum and maximum below.

Metric colours

Three stops per hardware metric: the colour shown at 0%, 50% and 100% load. Values in between blend through hue, so blue → yellow passes through green at 25%.

Loopback captures exactly what Windows is playing, so headphones work too. The strip stays dark whenever no sound is detected.

Mapping

Dominant colour picks the most vivid colour on screen. Whites, greys and blacks are ignored, so a green page element reads green instead of washing out to white. Average uses the screen's colourful pixels for the hue, so a white page with a strong accent still shows that accent. Colour changes ease in over about a tenth of a second.
